# 提瓦特心途

原神同人角色性格探索网站，适配手机竖屏。七个地区分别设有密钥入口、50 道生活化情境题和独立角色池，共 350 题、108 位角色。

## 正式网站

首页直接进入地区选择。正式发布仅使用 `dist/` 中的网站文件，不包含本地尺寸检查页、预览工具、测试代码或明文密钥。

## 内容与匹配

- 地区：蒙德、璃月、稻妻、须弥、枫丹、纳塔、挪德卡莱。
- 每地区五章，每章十题；包含情境单选、频率量表、双选和偏好排序。
- 题目以聚会、学习、出行、合作、日常安排和朋友相处等真实选择为基础。
- 每题只观察一个明确的行为维度，避免从道具、比喻或无关选择推断人格。
- 六维依次为社交能量、关怀方式、行动节奏、决策姿态、探索倾向和相处边界。
- 角色按当前地区限定匹配；结果包含角色资料来源、气质解读、六维图、相近角色与纪念卡。
- 数据和解释为同人创作，用于娱乐和自我观察，不是官方心理设定或专业心理测量。

## 运行与测试

需要 Node.js 20 以上与 Python 3：

```sh
npm start
npm test
npm run build
```

没有前端运行依赖。`npm run build` 使用 Python 标准库整理正式文件到 `dist/`，并检查模块引用和预览工具泄漏。

源码题库在 `data/questions/`，计分构造在 `data/question-builder.js`，角色资料在 `data/characters-*.js`。

新版题库使用独立的 v3 存档，不套用旧版题目的答案。答案只保存在当前浏览器，不上传服务器。

## GitHub Pages

仓库 Settings → Pages → Build and deployment 的 Source 选择 **GitHub Actions**。

推送 main 后，工作流会先执行完整测试，再构建并上传 `dist/`，最后部署 GitHub Pages。失败的测试会阻止部署。首次需要仓库所有者启用 Pages；工作流不保存个人访问令牌。

## 密钥与素材

`data/regions.js` 仅保存七组密钥的 SHA-256 摘要；明文密钥由活动发起者单独保管。当前为纯静态前端访问门槛，不能防止技术绕过，也不提供服务端授权。

角色事实参考官方角色介绍、HoYoWiki 和游戏资料转录，各角色的 `source` 字段提供链接。性格向量与气质标题为本站解释，并与角色身份资料分开展示。

角色图像版权归米哈游／HoYoverse，头像从 Enka 公开游戏资源 CDN 加载，加载失败时显示文字徽记。地图插画为原创示意 SVG，本站与官方无关联。
